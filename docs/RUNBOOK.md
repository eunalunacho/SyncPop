## 3. 분기표 (Decision Tree)

| 상황 | 판단 기준 및 증상 | 행동 지침 (Action) |
| --- | --- | --- |
| **유튜브 URL 인식 실패** | PoC 스크립트에서 "오디오를 추출할 수 없습니다", 권한 에러 등 반환 | 즉시 **B안(로컬 mp4 파일 업로드)**으로 전환. 83분 풀버전 포기, 미리 준비한 1곡짜리 직캠 영상으로 타겟 변경. |

## 4. 플랜 B 대응표 (Risk Management)

| 리스크 종류 | 감지 신호 (Signal) | 대응 방식 (Plan B) |
| --- | --- | --- |
| **API 호출 한도(Quota) 초과** | `429 Too Many Requests` 발생 | 즉시 병렬 처리(Concurrency)를 4개에서 2개로 축소. 지수적 백오프(Exponential Backoff) 적용. |
| **Cloud Run 배포/빌드 실패** | `gcloud` 에러, 도커 이미지 빌드 타임아웃 | 클라우드 배포 포기. 로컬호스트(Localhost) 띄우고 ngrok 등으로 임시 퍼블릭 URL 생성하여 데모 시연. |
| **라이브 처리 시간 초과** | 시연용 1곡 처리에 2분 이상 걸려 데모 영상(3분) 녹화 불가 | 라이브 처리 API 호출을 프론트에서 가짜로 흉내 내고(지연시간 10초 부여), 미리 하드코딩해 둔 JSON 캐시를 반환하여 데모 녹화 진행. |
| **프론트엔드 렌더링 지연** | 시간 보정(-0.5s) 스크롤 애니메이션 구현 시 버그 발생 | 자동 스크롤 기능 삭제. 영상 아래에 정적인 가사 리스트를 띄우고, 현재 가사 줄만 굵게(Bold) 표시하는 CSS로 타협. |

## 5. 컷 라인 (Drop Deadlines)

시간 부족 시 해커톤 심사 기준(Working Demo)을 지키기 위해 과감히 버릴 기능들입니다.

### 🔪 13:30 기준 미완성 시 폐기
- **진행 로그 실시간 스트리밍(SSE)**: 구현이 꼬이면 버리고, 백엔드에서 배열로 모아둔 로그를 완료 시점에 JSON 하단(`verification_log`)에 한 번에 반환하여 렌더링.
- **멘트(Talk) 번역 맥락 주입**: 이전 멘트 요약 로직이 복잡하면 폐기. 모든 구간을 독립된 곡으로 간주하고 기본 번역만 수행.

### 🔪 14:20 (Feature Freeze) 기준 미완성 시 폐기
- **"Sing Along" 팝업 UI & UNSURE 툴팁**: 화려한 CSS 오버레이 포기. 가창자(`crowd`) 텍스트 색상만 빨간색으로 다르게 칠하는 것으로 타협.
- **세트리스트 클릭 이동 기능**: 영상 옆에 목록만 띄워두고 재생 제어 기능 제거.
