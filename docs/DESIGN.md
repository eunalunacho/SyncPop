# DESIGN.md

본 문서는 프론트엔드 개발 에이전트가 단일 HTML(Vanilla JS/CSS) 기반으로 UI를 구현하기 위한 디자인 명세서입니다. 코드를 배제하고 구조와 스타일 원칙만 정의합니다.

---

## 1. 화면 흐름 및 와이어프레임 (ASCII)

화면은 입력 폼 ➔ 처리 중(로딩) ➔ 플레이어 3가지 상태로 전환됩니다. 단일 페이지 앱(SPA) 형태로 DOM을 교체하며 표시합니다.

### 1-1. 입력 화면 (Input Screen)

```text
+---------------------------------------------------------+
|                                                         |
|                       SyncPop Live                      |
|       [ YouTube URL을 입력하세요 (선우정아 라이브)  ]       |
|                       [ 시작하기 ]                        |
|                                                         |
+---------------------------------------------------------+
```

### 1-2. 처리 중 화면 (Processing Screen)
AI 에이전트가 뒤에서 열심히 일하고 있음을 시각적으로 어필하는 화면입니다.

```text
+---------------------------------------------------------+
|                                                         |
|  [||||||||||||||||||........] 65%                       |
|  상태: validating (자율 싱크 검증 중...)                        |
|                                                         |
|  [ Agent Validation Logs ]       누적 교정 건수: 2 건        |
|  +---------------------------------------------------+  |
|  | > 전체 구간 분할 완료 (총 23개 세그먼트)                  |  |
|  | > 곡 '원해' 가사 정렬 및 맥락 번역 중...                  |  |
|  | > 회차 1: 12:04 구간 1.8초 오차 발견 -> 재정렬 [FIXED] |  |
|  | > 회차 2: 관객 떼창 구간 환각 여부 검사 중...             |  |
|  +---------------------------------------------------+  |
|                                                         |
+---------------------------------------------------------+
```

### 1-3. 플레이어 화면 (Player Screen - Desktop)
모바일 환경에서는 영상이 상단, 가사/세트리스트 패널이 하단으로 떨어지는(Stacked) 구조로 적응(Responsive)합니다.

```text
+-----------------------------------+---------------------------------+
|                                   | [ 세트리스트 ≡ ]       [글자 크기 T/t] |
|                                   | 🎵 01. 가상의 곡 (00:00)           |
|                                   | 💬 02. 곡 소개 멘트 (03:15)         |
|      YouTube IFrame Player        | ------------------------------- |
|                                   | [🎵 가상의 곡]                      |
|                                   | 지나간 가사 1                      |
|                                   | Past line 1                     |
|                                   |                                 |
|                                   | ▶ 현재 부르고 있는 가사 원문    [✨] |
|                                   |   Currently singing english line|
|                                   |                                 |
| [▶] [||] [===========O  ] 12:04   | [!] 🎤 Sing Along! (떼창 구간)    |
|                                   | 관객이 부르는 가사 (포인트 컬러)  [?] |
+-----------------------------------+---------------------------------+
```

## 2. 플레이어 상세 동작 명세

### 2-1. 가사 패널 (Lyrics Panel)
- **표시 방식**: 한 줄에 '한국어 원문'을 크게, 바로 아래에 '영어 번역'을 작게 배치하는 2단 구성.
- **현재 줄 강조 (Active Line)**: `video.currentTime`과 JSON의 `start_display`를 비교하여 현재 줄의 투명도를 100%로 올리고 폰트 웨이트를 두껍게 변경. 스크롤 컨테이너의 중앙에 오도록 자동 스크롤(`scrollIntoView({ behavior: 'smooth', block: 'center' })`).
- **가창자 색상 구분 (Singer)**:
  - `artist`: 기본 텍스트 색상.
  - `crowd` (관객 파트): 메인 포인트 컬러(예: 네온 핑크/블루) 적용.
  - `both`: 기본 색상 유지하되 텍스트에 은은한 텍스트 섀도우(`text-shadow`) 적용.
- **멘트 구간 표시 (Talk)**: 라벨이 `talk`인 구간에서는 가사 대신 긴 문단 형태의 멘트 번역을 대화창처럼 표시.

### 2-2. 떼창 요청 배너 (Sing-along Request)
- JSON 라벨 중 `singalong_request: true`인 구간 도달 시, 가사 패널 상단(또는 화면 중앙)에 `"🎤 Sing along!"` 배너가 슬라이드인(Slide-in) 애니메이션과 함께 등장. 해당 구간이 끝나면 사라짐.

### 2-3. 검증 마커 (Validation Markers)
- **`[✨ FIXED]`**: 에이전트가 수정한 줄 옆에 작은 반짝이 아이콘 표시. 마우스 호버(또는 터치) 시 `fix_note` 내용이 툴팁으로 표시됨 (예: "1.5초 지연 보정됨").
- **`[? UNSURE]`**: 에이전트가 검증을 포기한 줄은 텍스트 투명도를 50%로 낮추고(흐리게 표시), 작은 물음표 아이콘 표시. 툴팁 내용: "AI가 가창자를 명확히 식별하지 못했습니다."

### 2-4. 세트리스트 네비게이션
- 화면 우측 상단(또는 측면)에 드롭다운이나 아코디언 형태의 목록.
- 아이콘으로 곡(🎵)과 멘트(💬)를 구분.
- 항목 클릭 시 IFrame Player의 `seekTo(start_time)` API를 호출하여 즉시 해당 구간으로 이동.

## 3. 디자인 토큰 (Design Tokens)

- **테마 (Theme)**: 어두운 콘서트장 느낌의 다크 모드(Dark Mode) 전용.
  - `--bg-base`: `#121212` (전체 배경)
  - `--bg-panel`: `#1E1E1E` (가사 패널 및 로그 박스 배경)
- **포인트 색상 (Accent Colors)**: 무대 조명을 연상시키는 채도 높은 네온 계열.
  - `--accent-main`: `#FF2A5F` (네온 핑크 - Sing along 배너, 강조 버튼 등)
  - `--accent-crowd`: `#00E5FF` (네온 시안 - 관객 가창 파트 가사 색상)
- **타이포그래피 (Typography)**: 가독성 높은 산세리프. 한글/라틴 동시 지원.
  - `font-family`: 시스템 폰트 스택 (`Pretendard`, `Apple SD Gothic Neo`, `Inter`, `sans-serif`).
  - `--text-primary`: `#FFFFFF` (원문 가사, 활성 줄)
  - `--text-secondary`: `#A0A0A0` (번역 가사, 비활성 줄)
- **스타일 규칙 (Spacing & Corners)**:
  - 모서리 둥글기 (`border-radius`): `8px` (카드, 패널) ~ `16px` (배너 등 부드러운 요소).
  - 여백 (`padding`): 요소 간 `16px`, 패널 간 `24px` 여유 있게 배치.
- **애니메이션 (Animation)**:
  - 활성 가사 전환 및 자동 스크롤 시 부드러운 전환을 위해 `transition: all 0.3s ease;`를 기본으로 사용. 화면이 번쩍거리는 등 과도하고 산만한 이펙트는 엄격히 금지.

## 4. 접근성 (Accessibility, a11y)

- **대비 (Contrast)**: 모든 텍스트는 배경과 4.5:1 이상의 명도 대비를 충족해야 함. (흐린 `UNSURE` 텍스트도 `#888888` 이상 유지).
- **글자 크기 조절**: UI 상단에 `[가]` `[A]` 버튼을 두어 가사 패널의 폰트 크기 증감 기능 제공 (기본 `16px` 기준 `12px` ~ `24px` 범위).
- **키보드 네비게이션**:
  - `Spacebar`: 영상 재생 / 일시정지 토글.
  - `↑` / `↓` 방향키: 이전 줄 / 다음 줄 시작 시간으로 영상 이동(Seek).
  - 모든 클릭 가능한 요소(세트리스트, 마커)에 `tabindex="0"` 및 Focus 외곽선 스타일(`outline: 2px solid var(--accent-main)`) 적용.
