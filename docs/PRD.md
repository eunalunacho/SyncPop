# PRD: SyncPop Live (Gemini 4 Argon Hackathon)

## 1. 문제 정의
- **대표 사용자**: 마리아 (Maria, 22세, 브라질, 대학생)
- **상황 및 문제**: 마리아는 한국 인디 음악의 팬으로, 선우정아의 83분짜리 미니콘서트 풀버전 영상을 유튜브로 시청하고 있습니다. 하지만 유튜브 자동 자막과 번역은 라이브 환경에서 무용지물입니다.
  - 밴드의 연주와 관객의 환호성을 기괴한 단어로 오인식하여 자막이 망가집니다.
  - 가수가 다음 곡의 슬픈 배경을 설명하는 멘트(Talk)의 감정선이 자막 번역에 전혀 연결되지 않습니다.
  - 가수가 마이크를 객석으로 넘기는 떼창(Sing-along) 구간에서는 자막이 아예 끊겨버려, 마리아는 현장의 분위기에서 소외감을 느낍니다.

## 2. 해결책
'SyncPop Live'는 Gemini 4 Argon의 1M 컨텍스트 윈도우를 활용해 83분짜리 라이브 오디오 전체를 이해하는 지능형 웹 플레이어입니다. 영상을 곡과 멘트 구간으로 대분할하고, 아티스트의 멘트 요약을 다음 곡의 번역 맥락으로 주입하여 몰입감을 높입니다. 특히, 자체적인 '검증 루프(Validation Loop)'가 오디오를 다시 듣고 가창자(Singer) 환각 오류와 싱크 오차를 스스로 교정하여, 떼창 구간을 정확히 안내하는 라이브 특화 시청 경험을 제공합니다.

## 3. 사용자 시나리오
1. **URL 입력**: 마리아가 웹앱에 선우정아 콘서트 유튜브 URL을 입력합니다. (미리 분석된 캐시가 즉시 로드됨)
2. **세트리스트 확인**: 화면 우측에 영상 전체의 세트리스트(곡 목록과 멘트 구간)가 타임라인 형태로 나타납니다.
3. **곡 선택**: 리스트에서 "원해"를 클릭하면 해당 구간부터 영상이 재생됩니다.
4. **가사·번역 싱크 시청**: 가수의 실제 발성에 맞춰 영어로 번역된 가사가 부드럽게 스크롤 됩니다. 직전 멘트의 감정선이 반영된 자연스러운 번역입니다.
5. **떼창 구간 안내**: 곡 후반부, 가수가 객석으로 마이크를 넘기자 화면에 "🎤 Sing Along!" 안내가 뜨며 관객이 부를 가사 파트가 강조됩니다.
6. **멘트 번역**: 곡이 끝나고 아티스트가 이야기하는 구간(Talk)에 진입하면, 자연스럽게 인터뷰 형태의 번역 자막으로 전환됩니다.

## 4. 기능 목록 및 완료 기준 (Done)

### Must-have (필수 - 14:20 기능 동결 전 완료)
- **유튜브 IFrame 임베드 (A안)**
  - *Done*: 서버 다운로드 없이 URL만으로 영상을 재생하고 currentTime을 동기화함.
- **전체 영상 세트리스트 분할 (thinking: low)**
  - *Done*: 전체 오디오를 분석해 `song`, `talk`, `singalong`, `applause`, `credits`, `other` 라벨로 구간을 나누고 JSON으로 캐싱함.
- **맥락 기반 곡 단위 처리 및 번역 (thinking: medium)**
  - *Done*: 곡 단위 오디오에 대해 직전 talk 요약을 맥락으로 주입하여 줄 단위 가사/번역을 추출. (화면 표시 시 모든 줄의 시간을 -0.5초 앞당겨 렌더링).
- **에이전트 검증 루프 (thinking: medium/high)**
  - *Done*: 최대 2회 반복 제한.
    1. 1.5초 이상 틀린 줄 재조정
    2. 누락 줄 복구
    3. 가창자 식별 질문("이 구간에 관객 목소리가 분명히 들리는가? YES/NO/UNSURE")을 통해 환각 오류를 교정.
    - *통과 기준*: 줄 시작 오차 ≤ 1.0초.

### Nice-to-have (시간 남을 때)
- 실시간 에이전트 진행 로그 UI 표출.
- 한국어 가사의 로마자 발음(Romanized) 표기.

### Out of scope (구현 제외)
- 크롬 확장 프로그램, React 빌드 셋업.
- transcribe, Deep Research 등 보조 모델 연동.
- 다국어 번역, 아이돌 공식 응원법 기능.

## 5. 성공 지표 (데모에서 숫자로 보여줄 것)
- **섹션 경계 정확도**: 전체 분할 결과 중 멘트/곡의 시작 시간이 영상 공식 설명란 기준 5/5개 (100%)가 1초 이내로 일치.
- **평균 시간 오차**: 정답을 직접 확인한 가사 줄 기준, -0.5초 시프트 적용 후 화면 표출 오차 ≤ 1.0초 이내.
- **검증 루프 교정 수**: 환각(관객 소리가 없는데 both로 잘못 표기된 마지막 후렴 등)을 YES/NO/UNSURE 로직으로 1건 이상 스스로 교정한 내역을 로그로 증명.
- **처리 시간**: 전체 83분 분할 작업 약 8분, 곡 단위 라이브 처리 약 14초 (데모 시연 시 1곡 라이브 처리 속도로 어필).

## 6. 심사 기준 매핑
| 심사 기준 | 매핑되는 기능 및 지표 |
| --- | --- |
| **Working Demo** | FastAPI + 단일 HTML 구조로 4시간 내 에러 프리 달성. 14초 만에 1곡을 실시간 처리하는 라이브 데모 시연 성공. |
| **Problem & Impact** | 기존 STT가 완전히 붕괴되는 '떼창(Sing-along)' 구간을 분리 안내하여, 글로벌 팬들이 겪는 K-pop 직캠 시청의 가장 큰 페인포인트를 해결. |
| **Originality** | 1M 컨텍스트로 멘트의 감정을 번역에 연결하는 '맥락 주입', 객관식 문답으로 환각을 제어하고 오차를 깎는 '자율 검증 루프' 아키텍처. |
| **Clarity** | 기존 자막과 완벽히 차별화되는 세트리스트 UI 및 직관적인 "Sing Along" 시각 효과. 화면 우측에 뜨는 에이전트의 검증 과정 노출. |

## 7. 알려진 한계 (Known Limitations)
- **곡 제목 식별 의존성**: 곡 제목은 1순위로 화면 내 영상 자막에 의존하며, 자막이 없으면 가사로 유추합니다. 확실하지 않으면 "Unknown song"으로 처리됩니다.
- **시간 오차의 물리적 한계**: 모델 출력 타임스탬프가 구조적으로 실제보다 약 0.5초 늦게 찍히는 일정한 지연이 있습니다. 프론트엔드에서 -0.5초를 일괄 적용해 보정하지만, 완전 무결한 0.1초 단위의 밀리초 동기화는 1초 내외의 오차를 가집니다.
- **처리 시간 병목**: 83분 전체 분할에 8분이 소요되므로, 3분 데모 시연 중 전체 파이프라인을 실시간으로 구동할 수 없습니다. (전체는 캐시를 사용하고, 1곡만 라이브로 시연하는 방식으로 우회합니다).
